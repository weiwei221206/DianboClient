## 说明

本项目使用第官方服务接口，接口行为可能变化。请遵守相关服务条款，并仅播放自己有权访问的内容。仅供学习交流，严禁用于商业用途。

---

## 项目介绍

点波音乐是一个独立的桌面音乐播放器，基于官方接口在WinUI3开发，提供音乐发现、搜索、播放、歌单管理和同步歌词等功能。它通过独立的 mpv 音频后端播放歌曲，界面和播放控制均由本项目实现。

本项目与波点音乐官方无关联。歌曲能否播放以及可用音质取决于服务端返回的地址和当前账号权益。
